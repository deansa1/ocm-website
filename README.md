# The Orchestral Classroom Model website

Production-ready static website source for OCM.

## Pages
- Home
- About OCM
- The Six Zones
- In Practice
- Resources
- Training & Support
- Contact

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New > Project** and import that repository.
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: leave blank / project root.
6. Deploy.

Every push to the repository will create a new Vercel deployment. Use Preview for review, then promote the approved deployment to Production.

## Assets
The site uses web-optimised versions of the supplied OCM master artwork in `assets/` while retaining the original master PNGs in the same project for future export work.
